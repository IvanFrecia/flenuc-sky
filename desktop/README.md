# Desktop launchers (Linux)

Maintainer machine setup for quick access:

## Icons

| File | Opens |
|------|--------|
| `Ivan Portfolio.desktop` | Live Cloud Run portfolio |
| `Task Development.desktop` | Active Sky Colab development task + UI |
| `Sky Colab.desktop` | Sky Colab transparency board (`duo ui`) |

## Install

```bash
# Icons + launchers (example paths)
install -Dm755 infra/scripts/../..  # use repo scripts or copy from ~/.local/share/ivan-portfolio

# Recommended: keep launchers under ~/.local/share/ivan-portfolio/bin
# and .desktop files under ~/Desktop and ~/.local/share/applications
```

Live URL default: `https://sky-portfolio-6k4smyyquq-uc.a.run.app`
